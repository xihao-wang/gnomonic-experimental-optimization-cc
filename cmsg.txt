feat: implement IoU metrics and visual validation for Phase 5

Implement rotated rectangle IoU calculation and visual validation tool
for debugging IoU correctness on fisheye images.

New modules:
- evaluation/lib/metrics.py
  - compute_rotated_iou(): IoU for rotated bboxes using OpenCV
  - match_predictions_to_ground_truth(): Greedy matching with IoU threshold
  - compute_precision_recall(): Precision, recall, F1 calculation

- evaluation/validate_iou_visual.py
  - Visual validation script for IoU debugging
  - GT visualizations: all bboxes on one fisheye image
  - Prediction visualizations: each bbox on separate image with IoU values
  - Configurable via evaluation/lib/config.py (IOU_VALIDATION node)

Output: evaluation/iou-visual-validation/

Tested on BOMNI dataset (10 samples)
