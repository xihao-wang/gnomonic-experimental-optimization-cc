feat: expand config search space, add visual sample caps, and wire empty CONFIG_IDS

— New projection configurations —
Added TEST#05 through TEST#22 (18 new configs) covering 4-projection,
6-projection (mirror grid pairs), and 9-projection variants. The 9-proj
group starts from fov_h=40deg (minimum full coverage) and explores
horizontal overlap levels, vertical FOV, and latitude independently.

— Empty CONFIG_IDS = run all —
SINGLE_CONFIG_RUN.CONFIG_IDS = [] now resolves to every config defined in
projection_configs_for_metrics.py, skipping folders that already exist
(OVERWRITE_EXISTING=False). Mirrors the existing COMPARATOR behaviour.

— Per-dataset visual sample cap —
Added METRICS_EVALUATION.VIS.MAX_SAMPLES sub-node with independent limits
for BOMNI, PIROPO, and CEPDOF (default: 50 each; 0 = no limit). The cap
gates both return_visuals and _save_visuals — metrics are never affected.
