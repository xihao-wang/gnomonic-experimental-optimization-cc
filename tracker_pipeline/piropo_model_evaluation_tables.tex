\section{Objectif}

Ce document regroupe les resultats experimentaux obtenus apres l'integration du module temporel appris dans le pipeline fisheye/gnomonic. Deux directions sont comparees :

\begin{itemize}
    \item \textbf{piste 1 : modele PIROPO 123train}, entraine avec \textit{test1 + test2 + test3 + training}, puis teste sur \textit{test4}, \textit{test6} et \textit{test9} ;
    \item \textbf{piste 2 : modele PIROPO 1236train}, entraine avec \textit{test1 + test2 + test3 + test6 + training}, puis teste sur \textit{test4} et \textit{test9}.
\end{itemize}

Une seconde evaluation verifie aussi si ces modeles PIROPO peuvent etre transferes vers l'ancien pipeline \textit{suivi-changement-apparence}, afin de distinguer les effets dus au modele temporel de ceux dus au domaine de donnees.
