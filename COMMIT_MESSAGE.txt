fix: Correct backprojected bbox rotation by 90 degrees

Backprojection was using standard polar coordinates while BOMNI uses vertical-up convention.

Issue:
- Backprojection used arctan2(dy, dx) - standard polar (0deg = right)
- BOMNI annotations use arctan2(dx, -dy) - vertical-up (0deg = up, clockwise)
- Result: Backprojected bboxes rotated 90deg off from ground truth

Fix:
- Changed calculate_radial_angle() to match BOMNI convention
- Now uses arctan2(dx, -dy) for angle calculation
- Backprojected bboxes now align correctly with ground truth

Files Changed:
- detection_pipeline/backprojection.py - Fixed angle calculation formula
